# LevelUp Gaming Community

Course project (IT Web Design). A multi-page gaming community site with
tournament listings, member profiles, and a community hub.

## Stack

HTML5 · CSS3 · JavaScript (vanilla)

## Running it

Open `index.html` in a browser, or:

```bash
python -m http.server 8000
```

Live demo: [view site](https://alexstaplesdesign.github.io/levelup-gaming-community/)

## Pages

- `index.html` — Homepage with featured games, tournaments, community stats
- `about.html` — Team and mission
- `games.html` — Games showcase
- `events.html` — Upcoming tournaments
- `community.html` — Stream team and member spotlights
- `contact.html` — Contact form
- `register.html` — Registration

## Notes

Modular CSS — separate files per page and component. Custom properties for
theming. Hamburger nav, form validation, and thank-you state transformations
in vanilla JS. There's a hidden easter egg page if you go looking.
